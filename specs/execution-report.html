Environment issues

Erratic Angular hydration

The same project page took 40 seconds in one run and 5.2 minutes in another. One window produced nine consecutive My Bookings failures that all died before any assertion — the login form never rendered — and passed later with no code change. Server HTML responds in 3–5 s, so this is client-bundle hydration, not an outage.

Cookie banner interception

The consent handler matched “Accept cookies” but marketing pages label the button “Accept all cookies”, so it looped without dismissing and swallowed every click. Pre-seeding localStorage.accept_cookies cut the home module from 7.2 m to 2.9 m.

Does anything from the test design remain unimplemented?

Every module is implemented. Not every individual case is. The design document holds 551 written cases (611 when the generic Activities pattern is expanded across its 13 modules); the suite contains 286 tests. That gap is two different things:

Consolidated — most of the gap, intentional

A single test frequently covers several design rows. One “all six status tabs are present” assertion subsumes six per-tab cases. This is deliberate: splitting them would multiply a run that already costs minutes per test without adding signal.

Genuinely unautomated — roughly 60–80 cases

  • Error injection (SHL-14, BST-11/12, BSM-12, XCT-10) — needs page.route() mocking, not built.
  • OTP flows (MYI-05/09/10) — the code cannot be received.
  • Concurrency (BST-06, BSM-10, XCT-15) — needs two coordinated sessions.
  • Visual and motion — carousel behaviour, map pin ↔ card highlighting, colour contrast, screen-reader announcement.
  • External redirects — asserted by href only; destinations are never loaded.
  • Booking depth (BST/BSM/BSC) — largely folded into the existing BOOK-01 journey rather than written as discrete cases.

Decisions needed to close the remaining gap

A disposable account or reset hook

Unblocks all eight destructive cases in one move. Today they cannot run twice against a shared beneficiary whose booking state the rest of the suite depends on.

Seeded fixture data

An invoice, a cancelled booking and a resale-eligible unit would convert most of the 26 conditional skips from guards into real coverage.
